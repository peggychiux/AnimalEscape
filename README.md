4 vs 1 非對稱多人逃脫遊戲的灰盒原型。企劃與開發計畫在 `Docs/`。

- Unity 版本：**6000.3.25f1**（Unity 6.3 LTS）

- 目前進度：**M3（捕捉籠與救援）已完成**，2026-11-17 用兩個視窗在三張地圖上驗證。之前完成的：M2（追與抓）和開場越獄。M2 是 2026-11-15 用三個視窗（1 人類＋兔子＋猴子）實際執行驗證的；

## 第一次開啟

1. 打開 Unity Hub → **Add** → **Add project from disk** → 選這個資料夾（`AnimalEscape`）。
2. 用 6000.3.25f1 開啟。第一次會下載套件並匯入，需要幾分鐘。
3. 匯入完成後會**自動建立**場景 `Assets/_Project/Scenes/Main.unity` 並開啟。
   沒有自動建立的話，從選單執行 **Tools > Animal Escape > 重建原型場景**。
4. 按 **Play**。

## 怎麼玩（目前的原型）

### A. 同一台電腦（不需要任何雲端設定）

1. 選單 **Window > Multiplayer > Multiplayer Play Mode**，勾選 **Player 2**，會多開一個視窗。
2. 按 Play。在主視窗按「建立本機房間」，Player 2 視窗會**自動加入**，不用手動按。
   （不想自動加入的話，把 `GameConfig.asset` 的 Virtual Players Auto Join Local 取消勾選。）
3. 兩邊各自在「選擇身分」畫面選一個身分，就會出現在地圖上。
4. 要操作哪個視窗就先點一下那個視窗的遊戲畫面；沒有被點選的視窗不會接收鍵盤和滑鼠。

### B. 兩台電腦（線上房間）

1. **Edit > Project Settings > Services**，登入 Unity 帳號並連結一個 Unity Cloud 專案（免費）。
   如果建立房間時顯示服務未啟用，到 Unity Cloud Dashboard 把這個專案的 **Relay** 和 **Lobby** 打開。
2. 一台按「建立線上房間」，把左上角的房間代碼給另一台；另一台輸入代碼後按「輸入代碼加入」。
3. 另一台電腦可以開同一份專案，或用 **File > Build Profiles** 打包一份執行檔。

### 身分

進房間後先選身分。**每種身分只能有一位**（人類一位，四種動物各一隻），被選走的會變灰。左上角的「換身分」可以隨時重選。

| 身分 | 身高 | 速度 | 跳躍高度 | 鑽得進通風管 |
|---|---|---|---|---|
| 人類 | 1.8 m | 5.0 m/s | 1.0 m | ✗ |
| 兔子 | 0.6 m | 6.5 m/s | 1.6 m | ✓ |
| 猴子 | 0.9 m | 5.5 m/s | 1.3 m | ✗ |
| 浣熊 | 0.7 m | 5.0 m/s | 1.0 m | ✓ |
| 烏龜 | 0.5 m | 3.5 m/s | 0.5 m | ✓ |

數值都在 `GameConfig.asset`，可以直接調。改了身高、半徑或顏色之後要執行一次「重建原型場景」，外觀才會跟著變。

### 視角

- **人類是第一人稱**：鏡頭在眼睛的位置，看不到自己的身體，畫面中央有一個小準星。視野受限，動物才有躲藏和繞路的空間。
- **動物是第三人稱**：鏡頭跟在角色背後，看得到自己，也能越過障礙物偷看人類在哪。

這和《黎明死線》的分法一樣（抓人的一方第一人稱，逃的一方第三人稱）。想比較別的組合，改 `GameConfig.asset` 的
Human View Mode、Animal View Mode 就好，Play 中改也會馬上生效。

### 地圖

場景是「溫室＋周邊研究設施」，80 x 60 公尺，裡面沒有隔間牆，靠植栽、家具和水來擋視線與路線。
有三張格局不同的地圖，三張都保留（2026-11-16 決定），每一局可以選：

| 地圖 | 格局 | 特色 |
|---|---|---|
| **A 圓環** | 溫室在正中央（水池＋兩圈弧形植栽），四個設施區在四角 | 中間一圈環狀動線，最好認路 |
| **B 長廊** | 溫室是一條貫穿東西的花園，設施區在南北兩側 | 花園裡是交錯的植栽牆，要左右繞；追逐感最強 |
| **C 島群** | 整個場地都是花園，一條溪流從西北斜到東南，設施像小島散落 | 沒有一條路是直的，變化最多 |

**怎麼切換**：大廳畫面最上面有「地圖」按鈕（開房的人決定）；進房間後，主機左上角有「換地圖」按鈕，
按了所有人會回到選身分畫面，在新地圖重新出生。上次選的地圖會記住。

三張地圖用的是同一套積木，地板顏色代表區域：

| 區域 | 地板 | 裡面有什麼 |
|---|---|---|
| 溫室／花園 | 綠 | 高樹籬（擋視線）、矮植栽箱、樹、水池或溪流 |
| 籠舍區 | 黃 | 一格格矮圍欄；部分有頂蓋，小動物可以躲進去 |
| 研究室 | 淺藍 | 矮實驗台和高設備櫃交錯；部分高櫃底下有管道 |
| 育苗區 | 土色 | 一排排植栽桌，小動物可以從整排桌子底下鑽過去 |
| 倉庫 | 深灰 | 高貨架排成要拐彎的窄巷；橘色的是貨車出口（之後動物逃脫的地方，現在只是記號） |

可以試的東西：

- **水**：人類可以涉水，但速度剩一半（走橋比較快）；烏龜在水裡是 1.6 倍速，比人類跑步還快一點。
  兔子、猴子、浣熊進不去，要走橋；水上另外有藍綠色的**管道**，只有兔子、浣熊、烏龜鑽得過。在水裡的角色看起來會沉下去一截。
- **管道**（藍綠色，內部 0.8 公尺）：高櫃、貨架、樹籬底下也有，小動物直接穿過去，人類和猴子要繞整排。
- **矮圍欄和矮植栽箱**（1.45 公尺）：人類看得過去但跳不過；兔子和猴子跳得過；浣熊和烏龜跳不過。
- **桌子和籠舍頂蓋**（底下淨高 0.85 公尺）：兔子、浣熊、烏龜鑽得進去，猴子和人類不行。
- **台階**：0.5、1.0、1.5 公尺三階，可以比較各身分的跳躍高度（A 在北側中間、B 在北側兩區之間、C 在東北的籠舍前）。
- **名牌**：只有「看得到本人」時才會顯示對方的名牌，躲在樹籬後或管道裡不會被名牌出賣；隔著水看得到對岸。

### 開場越獄

- 人類從**研究室**出發。動物開場各自關在自己的**收容區**（有頂的鐵網籠子，門是黃色的）：
  兔子在籠舍區旁的柵欄、猴子在育苗區旁罩著樹的大籠子、浣熊在倉庫旁的置物籠。**烏龜沒有被關**，直接出生在池塘裡。
- **撬鎖**：走到黃色的門邊，**按住 E** 不放，畫面下方有進度條；浣熊 5 秒、猴子 8 秒、兔子 11 秒。放手或走開進度會歸零。
- 門打開的那一刻，門邊的動物有 3 秒保護，網子抓不到。門開了之後人類也進得去。
- 任何動物都可以撬任何一道門（從裡面或外面都行），所以先出來的可以去幫隊友開門；秒數看撬的那隻。
- 隔著鐵網，人類的網子打不到裡面；但裡外互相看得到，名牌也會顯示。
- 每次選一種動物出生，牠的收容區會重新鎖上；換地圖時全部重新鎖上。

秒數和水裡的速度倍率在 `GameConfig.asset` 的「開場越獄：撬鎖」和「水」。

### 追與抓

- **人類揮網**（滑鼠左鍵）：打得到正前方左右各 50 度、2.6 公尺內的動物，一次最多網住最近的一隻。
  按下去 0.2 秒後才判定（動物可以趁這時候閃開），揮完冷卻 1.5 秒；冷卻中網子會垂下來，動物看得出來。
  中間隔著樹籬、櫃子、牆就打不到；躲在管道深處（離管口超過約 0.8 公尺）也打不到。
- **被網住**：動物倒在地上不能動，**連按空白鍵**掙脫（畫面下方有進度條，不按會慢慢掉）。
- **扛走**（E）：人類走到被網住的動物旁邊（2 公尺內）按 E 扛起來，再按一次放下。
  扛著的時候速度剩七成、不能揮網。被扛著的動物可以繼續連按掙脫，但比在地上難。
- **隊友推撞**：自由的動物**全速撞上**扛著隊友的人類（慢走不算），隊友就會被救下來，人類踉蹌 2 秒。
- **掙脫或被救之後**有 3 秒保護，網子抓不到；動物自己從肩上掙脫時，人類也會踉蹌 1.2 秒。
- 被網住或被扛著的時候不能換身分。

這些數字都在 `GameConfig.asset` 的「追與抓」，是還沒經過試玩的初始值。

### 捕捉籠與救援

- 每張地圖有 **5 個捕捉籠**（紅框的小籠子，1～5 號），每籠關一隻。
- **關進去**：人類扛著動物走到空籠子旁按 **E**。不在籠子旁按 E 是放下。
- **倒數**：第 1 次被關 120 秒、第 2 次 80 秒；**第 3 次被抓直接送進實驗室**，倒數歸零也送進實驗室。
  籠子裡可以走動，但出不去。被關的次數在每次選身分時歸零。
- **救援**：隊友走到籠子旁**按住 E 3 秒**就能救出來。被救的動物有 5 秒保護；保護中被網子打到只會變慢一下。
- **反守籠**：人類在籠子 8 公尺內待超過 10 秒，那個籠子的倒數會暫停（籠子上顯示「暫停中」），人類離開才繼續。
- **籠邊警報**：人類走進關著動物的籠子 15 公尺內，動物畫面右上角的籠子列表會標出「人類在附近！」。
- 關著動物的籠子上方會顯示「幾號籠、誰、還剩幾秒」，所有人都看得到。

這些數字在 `GameConfig.asset` 的「捕捉籠與救援」。

### 實驗室與門禁卡

- 每張地圖的研究室角落有一間**實驗室**（紫色的房間、紅色招牌、門邊有讀卡機）。牆和屋頂都不透明，外面看不到裡面。
- 籠子倒數歸零、或第 3 次被抓的動物，會被送進實驗室。裡面是**派對**：
  - 可以自由走動、跳上舞台和懶骨頭，撞球玩（球是大家共用的，誰撞都會滾）；
  - **數字鍵 1～4** 做表情：揮手、跳舞、轉圈、開心跳（別人看得到）；
  - 牆上的**大螢幕**播還在場上的隊友，走到螢幕前的控台按 **E** 換人看；沒有隊友在場上時播全景；
  - 左上角「換身分」可以重新出生；畫面下方的「**離開遊戲**」回到大廳，這局算沒逃出去。
    主機按的話只會退出這一局、房間繼續開著（主機一離開房間，所有人都會斷線）；要關房間用左上角的「離開房間」；
  - 實驗室裡外的聲音互相聽不到。
- **門禁卡**：每次開房（或換地圖）在 3 個候選位置隨機出現 1 張青色的卡。自由的動物走過去就撿起來，卡會浮在牠頭上，
  所有人都看得到誰拿著；拿著卡被網住，卡會掉在原地。
- 拿著卡在實驗室**門外按住 E 5 秒**，裡面的動物**全部**放出來，有 5 秒保護。**整場只能刷一次**；
  實驗室裡沒人時刷不了。被門禁卡救出來的動物，下次被抓直接回實驗室。
- 右上角的狀態列表會寫「實驗室裡有誰」和「門禁卡在哪」。

這些數字在 `GameConfig.asset` 的「實驗室與門禁卡」。

### 聲音

- **人類的腳步聲**：動物聽得到。跑步 20 公尺內、慢走（Shift）8 公尺內聽得到，站著不動沒有聲音。
- **動物的項圈鈴鐺**：人類聽得到。跑步 18 公尺內、慢走 5 公尺內聽得到，站著不動不會響。
- **叫聲**：動物被網住、被關進籠子時會叫，整張地圖都聽得到。
- 聽到的聲音會在**畫面邊緣出現聲波圖示**，指出大概的方向（越近越大），2 秒後淡掉；不會告訴你確切位置。
- 音效現在是程式合成的簡單聲音，之後會換成正式音效。數字在 `GameConfig.asset` 的「聲音」。


### 比賽（M4）

- 進房間後是**準備中**：選好身分可以自由練習（破壞、控制台、出口都能用，但不計時）。
- 主機按上方的「**開始比賽**」（至少要 1 個人類和 1 隻動物）：所有人回到出生點、收容區全部鎖上、混亂值歸零、壞掉的東西恢復。
  比賽中不能換身分、不能換地圖；還沒選身分的人只能看，等下一局。
- **一局最長 10 分鐘**，上方中央會顯示剩下的時間、混亂值和出口的狀況。
- **破壞**：動物走到花盆、燒杯、飼料桶、紙箱堆、大盆栽、實驗機器…旁邊按 **E**。小東西按一下就倒（混亂值 +2%），
  中的要按住 1.5 秒（+5%），大的要按住 3 秒（+10%）。人類聽得到撞擊聲（小 15、中 25、大 40 公尺內），畫面邊緣會出現「東西倒了！」。
  每張地圖大約 40 個，壞了這一局就不會恢復。動物看得到的可以弄倒的東西，頭上有**橘色圓點**寫著加多少混亂值；
  走到碰得到的距離時，那個東西會閃黃色、頭上變成「E」。人類看不到這些標記。
- **保全控制台**（人類）：每張地圖 3 台（藍色地墊、帶螢幕的桌子）。在旁邊**按住 E 5 秒**，混亂值 −15%；那一台要冷卻 60 秒。
- **混亂值滿 100%**：保全系統當機，出口解鎖（之後混亂值不會再降，控制台也沒用了）。
- **出口**（橘色的大門，A 在北牆中間、B 和 C 在西牆）：動物在門前**按住 E** 開門。一隻要 10 秒，每多一隻快五成；放手進度會留著，被網住就停。
- **貨車**：門打開後貨車開始倒數 **90 秒**。動物走進車廂就算上車（網子抓不到），走出來就是下車（可以回去救人）。
  車廂入口很矮，人類進不去。
- **結束**：貨車倒數結束、10 分鐘到、或場上沒有自由的動物了（都上了車、被關、或在實驗室）。
  照貨車上有幾隻動物：**4 隻動物完勝、3 隻動物勝、2 隻平手、0～1 隻人類勝**。結算畫面會列出每隻動物有沒有逃出；主機按「**再來一局**」。

這些數字在 `GameConfig.asset` 的「M4」那幾段。

### 電腦動物

- 一個人也能測：主機選人類，在左上角面板按「**＋ 加電腦動物**」（可以按好幾次，自動挑還沒人選的動物；「－ 移除」拿掉最後加的那一隻），
  再按「開始比賽」。準備中電腦動物會站著等。比賽中不能加。
- 電腦動物會：撬鎖逃出收容區、找最近的東西弄倒（每弄倒一樣會先慢慢閒晃一下）、看到人類靠近就逃、被網住或被扛著連按掙脫、
  混亂值滿了去開出口、上貨車。還不會：救隊友、刷門禁卡、鑽通風管和桌底、跳圍欄。
- 電腦也佔房間名額（最多 5 個），真人進來時位子不夠會自動讓一隻電腦出去。名單、名牌、結算都標「（電腦）」。
- 調整：`GameConfig.asset` 的「電腦動物」（多近會逃、多久休息、每秒按幾下掙脫…）。

### 操作

| 動作 | 按鍵 |
|---|---|
| 移動 | WASD（A／D 是橫著走；手把左搖桿） |
| 前後走（方向鍵） | ↑↓ |
| 慢走 | 按住左 Shift（手把按下左搖桿） |
| 跳 | 空白鍵（手把 A） |
| 轉視角 | 滑鼠或 ←→ 方向鍵（手把右搖桿） |
| （人類）揮網 | 滑鼠左鍵（手把右扳機） |
| （人類）扛起／放下／關進籠子 | E（手把 X） |
| （動物）撬鎖、救隊友、刷門禁卡、開出口 | 按住 E（手把 X） |
| （動物）弄倒東西 | E（大的要按住） |
| （人類）保全控制台 | 按住 E |
| （實驗室）表情 | 數字鍵 1～4 |

方向鍵轉鏡頭是照《黎明死線》的做法（2026-11-17 使用者決定）；`GameConfig` 的 `arrowKeyTurning` 關掉的話，方向鍵就和 WASD 一樣是移動。

```
    Match/       整局共用的狀態（MatchState：地圖、收容區的門、門禁卡）和地圖上的機關（捕捉籠、收容區的門、實驗室、球、門禁卡的外觀）
    Network/     連線、開房間、加入房間
    Player/      玩家狀態（PlayerSlot）、場上角色（PlayerAvatar）、移動、鏡頭（PlayerCamera）、主機端的角色產生、
                 追與抓（PlayerCapture：揮網、被網住、掙脫、扛走、推撞）
    UI/          大廳、選身分、遊戲內資訊面板、名牌
    Editor/      PrototypeBuilder：用程式產生場景與預製物
                 DevTestDriver：自動測試用的遙控器（見下方「自動測試」）
    DevTools/    把編譯結果與 Console 訊息寫到 Logs/，方便 Claude 讀取
  Config/Resources/GameConfig.asset   所有可調數值（自動產生）
  Scenes/ Prefabs/ Materials/ Settings/   （自動產生）
Docs/            企劃書與開發計畫
Tools/           record_demo.py：錄示範影片用的劇本（座標還是舊地圖的，地圖定案後要重寫）
```

## 重要約定

- **場景和預製物是程式產生的。** 要改場景內容或角色組成，請改 `PrototypeBuilder.cs` 再執行「重建原型場景」，不要直接在編輯器裡改（重建時會被蓋掉）。
- **數值只改 `GameConfig.asset`**，重建場景不會蓋掉它。
- **Active Input Handling 必須是 Both**（Project Settings > Player）。原型的介面用 IMGUI，設成只有新 Input System 時按鈕會沒反應。
  因為這個設定，Console 會出現一則「This project uses Input Manager, which is marked for deprecation」的警告，可以忽略。

## 版本控制

專案放在 GitHub（私人）：<https://github.com/peggychiux/AnimalEscape>，分支是 `main`。
`.gitignore` 已經排除 Unity 自動產生的資料夾（Library、Logs、UserSettings 等），所以儲存庫很小。

每做完一個里程碑存一版：

```
git add -A
git commit -m "M3: 捕捉籠與救援"
git push
```

- 在這台 Mac 上第一次 `git push` 時會要你登入 GitHub；用 GitHub Desktop 開這個資料夾，或照終端機的提示用瀏覽器登入都可以。
- **另一台電腦（包含 Windows）要拿專案**：先在 GitHub 把對方加成這個 repo 的協作者，對方執行
  `git clone https://github.com/peggychiux/AnimalEscape.git`，再用 Unity Hub 開啟（Unity 6000.3.25f1）。
  第一次開會花幾分鐘重建 Library。
- `.gitattributes` 裡有 Git LFS 的規則（圖片、模型、音效）。目前專案沒有這類檔案，所以還用不到；
  之後加入美術素材之前，每台電腦先執行一次 `git lfs install`。

## 出問題時

Unity 的編譯錯誤與 Console 訊息會同步寫到：

- `Logs/claude-compile.txt`：最近一次編譯的錯誤與警告
- `Logs/claude-console.txt`：這次開啟編輯器以來的 Console 訊息

把這個資料夾接給 Claude 後，Claude 可以直接讀這兩個檔案找問題。

**Player 2 沒有自動加入**（主視窗的 Console 出現 `NetworkConfig mismatch`）：通常是剛重建過場景和預製物，
第二個視窗手上還是舊的那一份。隨便改一支程式讓 Unity 重新編譯一次（或在 Multiplayer Play Mode 視窗把 Player 2
取消勾選再勾回來），再按 Play 就會好。

## 自動測試（給 Claude 用的遙控器）

為了不用搶鍵盤滑鼠就能測多人情境，專案裡有一支只在編輯器裡運作的 `DevTestDriver`。
Unity 開著的時候，它會讀 `Logs/claude-commands.txt` 裡的指令（例如「P1 選兔子」「P2 走到某個座標」「存一張畫面」），
結果寫到 `Logs/claude-test-results.txt`，畫面存到 `Logs/shots/`。主視窗和 Player 2 視窗都會照做。

- 它只會執行固定的那幾種測試動作，不會執行任意程式，也不會被打包進遊戲。
- 沒有新指令的時候它什麼都不做。如果你在 Unity 裡看到角色自己動，就是 Claude 正在跑測試。
- 指令格式寫在 `Assets/_Project/Scripts/Editor/DevTestDriver.cs` 開頭的說明裡。
- 它也能錄影：`Tools/record_demo.py` 是一段約一分鐘的三人示範劇本（兔子視角），之後換了美術想重錄可以直接用。
